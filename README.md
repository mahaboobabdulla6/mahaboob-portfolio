# Mahaboob Basha Shaik — DevOps Portfolio

A responsive, single-page portfolio built from the supplied resume, portrait, and reference video.

## Run locally
Open `index.html` in a modern browser. For a local server, run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Customize
- Replace `assets/profile.jpeg` to change the portrait.
- Edit `index.html` to update resume details, project descriptions, and contact links.
- Edit `style.css` for visual styling.
- Edit `script.js` for navigation and reveal animations.

All portfolio text is based on the supplied resume. Project architecture illustrations are CSS-based concept visuals, not screenshots of deployed infrastructure.
